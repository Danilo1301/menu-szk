# MenuSZK

For developers: You can create menus, custom layouts, play audio, and other stuff.

You can check the file **menuSZK/imenuSZK.h** for more features

# Required / optional mods

**Required:** GTA SA APK with AML, GTA version 2.00 or GTA 2.10

**Recommended:** libBASSMod *(you can find on AML Discord)*

**Optional:** libSAUtils *(you can find on AML Discord)*

# Installation

Make sure you installed all required mods first

1. Download the .zip of the mod from the Releases page

Releases: https://github.com/Danilo1301/menu-szk/releases

2. Copy the content of the folder **com.rockstargames.gtasa** to your gta folder

3. Open the game
